Implementation decisions
------------------------
* Country is chosen in the cart, validated server-side, and locked for that
  Checkout session. Hosted Checkout cannot scope individual shipping rates to
  different countries. Change the destination by returning to the cart.
* total_cents retains the item subtotal; shipping_cents is delivery;
  amount_paid_cents records Stripe's actual total in the payment transaction.
* Both paid and already_paid may claim an unsent email, per the clarified request.
  Missing sender or API key skips with a warning. Failed sends release their owned
  claim and return webhook 500. Provider idempotency adds a second deduplication
  layer, but a process crash after claiming can require manual recovery.
* Admin auth uses a fresh anon client per operation; no shared signed-in state,
  refresh token storage, or refresh process. Re-login when the access token expires.
  Sign out clears the browser cookie. Dates use Malaysia time; items counts units.
* Manually entered out-of-range pages redirect to a valid page while retaining
  the status filter. Tied creation dates use id as a stable secondary sort key.
