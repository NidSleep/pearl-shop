## Product Purpose

Sell pearl jewellery in MYR with delivery to Malaysia and Singapore. Visitors browse and filter the collection, inspect product details, add pieces to a cart, and use hosted Stripe Checkout.

## Capabilities and Constraints

Next.js 16 App Router, TypeScript, Tailwind v4 and Supabase. This redesign is visual and UX only: preserve all pricing, stock, database, authentication, payment, email, rate-limit and API logic. No new dependencies, browser use, git commands or changes to .env.local. Keep static colour tokens and component layers in the existing two CSS entry files.

## Brand Commitments

The existing name is Pearl Shop. The owner rejects the current pale, generic presentation and asks for a confident luxury jewellery identity, strong contrast, editorial typography, and excellent desktop and mobile presentation. The agent is explicitly delegated the choice of one concept.
